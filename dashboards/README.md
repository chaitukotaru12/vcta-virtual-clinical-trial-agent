# Interactive dashboards

Two interactive dashboards were built from these results in Claude (claude.ai):

| Dashboard | What it shows |
|---|---|
| **VCTA Trial Design Advisor (protocol only)** | Red flags, literature benchmarks, recommendations, design options, in-trial checkpoints, safety triggers, what-if charts and the 1,000-participant virtual cohort with a participant browser. Uses only the protocol and pre-trial literature. |
| **VCTA Virtual Trial Simulation** | The first simulation: validation, what-if charts, critic review, the virtual cohort and the retrospective comparison with the published trial. |
